# hotel-ai-assistant

An AI-powered hotel service agent system with RAG, tool routing, and conversational UI.  
面向酒店行业的 AI 服务智能体系统，支持 RAG 检索增强、工具路由与对话式 UI。

---

## 🌟 Project Overview / 项目概览

Hotel AI Assistant is an AI-powered conversational system designed for hotel service scenarios.  
It supports natural language interaction for guests, including restaurant recommendations, attractions, FAQs, room services, and concierge operations.

The system combines:
- Retrieval-Augmented Generation (RAG) via Qdrant
- Intent classification and tool routing
- Structured backend services (Spring Boot + JPA)
- Rich frontend UI (Vue 3)
- Extensible AI orchestration layer (LangChain)

---


Hotel AI Assistant 是面向酒店服务场景的 AI 对话系统。  
支持用户通过自然语言获取餐厅推荐、景点信息、常见问题、客房服务及礼宾服务等能力。

系统融合：
- 基于 Qdrant 的 RAG 检索增强生成
- 意图识别与工具路由
- Spring Boot + JPA 后端服务
- Vue 3 富交互前端
- 可扩展 AI 编排层（LangChain）

## 🛠️ Tech Stack / 技术栈

### Frontend / 前端
- Vue 3
- TypeScript
- Vite

### Backend / 后端
- Spring Boot
- Java 17+
- Spring Data JPA
- PostgreSQL

### AI & Retrieval / AI 与检索
- LangChain4j (AI orchestration layer)
- Qdrant (Vector database for RAG)
- Embedding model (Jina / OpenAI-compatible)
